
# 실습과제1

```c
Person get_data(void);
void put_data(Person data);
```
- get_data 함수는 매개변수 없이 구조체를 반환하고, put_data 함수는 구조체를 전달받아 출력한다.

```c
Person get_data(void) {
    Person data;
    scanf("%d", &data.num);
    scanf("%s", data.name);
    scanf("%s", data.account);
    return data;
}
```
- 구조체 변수 data를 선언하고 학번, 이름, 주소를 입력받은 후 구조체 전체를 반환한다.

```c
data = get_data();
put_data(data);
```
- get_data 함수에서 반환된 구조체를 data에 저장하고 put_data 함수에 전달한다.

```c
void put_data(Person data) {
    printf("%s %d %s", data.name, data.num, data.account);
}
```
- 전달받은 구조체의 이름, 학번, 주소를 출력한다.

# 실습과제2

```c
void get_data(Student* plist);
Student get_best(Student* plist);
```
- get_data 함수는 구조체 포인터를 이용하여 학생 정보를 입력받고, get_best 함수는 가장 높은 성적을 가진 학생의 구조체를 반환한다.

```c
void get_data(Student* plist) {
    for (int i = 0; i < 3; i++) {
        scanf("%s", plist[i].name);
        scanf("%d", &plist[i].grade);
    }
}
```
- 구조체 포인터를 이용하여 학생 3명의 이름과 성적을 입력받는다.

```c
Student get_best(Student* plist) {
    Student best;
    best.grade = plist[0].grade;
    strcpy(best.name, plist[0].name);
```
- 구조체 변수 best를 선언하고 첫 번째 학생의 이름과 성적을 초기값으로 저장한다.

```c
for (int i = 0; i < 3; i++) {
    if (best.grade < plist[i].grade) {
        best.grade = plist[i].grade;
        strcpy(best.name, plist[i].name);
    }
}
return best;
```
- 반복문을 이용하여 학생들의 성적을 비교하고 현재 성적보다 높은 학생을 발견하면 best의 이름과 성적을 변경한 후 반환한다.

```c
best = get_best(list);
printf("%s %d", best.name, best.grade);
```
- get_best 함수에서 반환된 구조체를 best에 저장하고 가장 높은 성적을 가진 학생의 정보를 출력한다.

# 실습과제3

```c
void get_data(Student* plist);
Student get_first(Student* plist);
```
- get_data 함수는 학생 정보를 입력받고, get_first 함수는 이름을 사전순으로 비교하여 가장 앞선 학생의 구조체를 반환한다.

```c
Student get_first(Student* plist) {
    Student first;
    first.grade = plist[0].grade;
    strcpy(first.name, plist[0].name);
```
- 구조체 변수 first를 선언하고 첫 번째 학생의 이름과 성적을 초기값으로 저장한다.

```c
for (int i = 0; i < 3; i++) {
    if (strcmp(first.name, plist[i].name) > 0) {
        first.grade = plist[i].grade;
        strcpy(first.name, plist[i].name);
    }
}
```
- strcmp 함수를 이용하여 이름을 사전순으로 비교하고 현재 이름보다 앞선 이름을 발견하면 first의 이름과 성적을 변경한다.

```c
return first;
```
- 모든 학생의 이름을 비교한 후 사전순으로 가장 앞선 학생의 구조체를 반환한다.

```c
first = get_first(list);
printf("%s %d", first.name, first.grade);
```
- 반환된 구조체를 first에 저장하고 해당 학생의 이름과 성적을 출력한다.

# 실습과제4

```c
void swap_struct(Point* pos1, Point* pos2);
```
- 두 구조체 변수의 주소를 전달받아 구조체의 값을 서로 교환하는 함수이다.

```c
Point pos1 = { 1,2 };
Point pos2 = { 3,4 };
swap_struct(&pos1, &pos2);
```
- 두 구조체 변수를 선언하고 각각의 좌표를 초기화한 후 주소를 함수에 전달한다.

```c
void swap_struct(Point* pos1, Point* pos2) {
    Point temp;
    temp = *pos1;
    *pos1 = *pos2;
    *pos2 = temp;
}
```
- 임시 구조체 변수 temp를 이용하여 두 구조체의 값을 서로 교환한다.

Point pos1 = { 2,4 };

SwapPoint(&pos1, &pos2);

```c
void SwapPoint(Point* pos1, Point* pos2) {
    Point temp;
    temp = *pos1;
    *pos1 = *pos2;

}
```
- 임시 구조체 변수 temp를 이용하여 첫 번째 구조체의 값을 저장하고 두 구조체의 값을 서로 교환한다.
